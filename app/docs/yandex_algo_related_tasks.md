# Связанные задачи для тренировки

Этот файл можно использовать без перехода по ссылкам. В каждой задаче есть контекст, вход, выход, примеры, ограничения и подсказка. Готового решения нет.

## Сортировка и отсортированные данные

### 1. Объединение пересекающихся интервалов

У тебя есть список встреч в календаре. Каждая встреча задана интервалом `[start, end]`, где `start` - начало, `end` - конец. Если две встречи пересекаются или касаются границами, их нужно объединить в один занятый промежуток.

Нужно вернуть список занятых промежутков без пересечений.

Сигнатура:

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    ...
```

Пример 1:

```python
intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
# result: [[1, 6], [8, 10], [15, 18]]
```

Пример 2:

```python
intervals = [[1, 4], [4, 5]]
# result: [[1, 5]]
```

Ограничения:
- `0 <= len(intervals) <= 10_000`
- каждый интервал имеет вид `[start, end]`
- `start <= end`

Что нужно понять:
- после сортировки по `start` пересекающиеся интервалы будут стоять рядом;
- достаточно хранить последний интервал в ответе и сравнивать новый интервал с ним.

Ожидаемая сложность:
- время: `O(n log n)`
- память: `O(n)`

### 2. Слияние двух отсортированных массивов

Даны два отсортированных массива `a` и `b`. Нужно вернуть новый отсортированный массив, содержащий все элементы из обоих массивов.

Сигнатура:

```python
def merge_sorted_arrays(a: list[int], b: list[int]) -> list[int]:
    ...
```

Пример:

```python
a = [1, 2, 5]
b = [2, 3, 4]
# result: [1, 2, 2, 3, 4, 5]
```

Ограничения:
- `0 <= len(a), len(b) <= 100_000`
- массивы уже отсортированы по возрастанию
- нельзя использовать `sorted(a + b)`

Что нужно понять:
- держи два указателя: один на `a`, второй на `b`;
- каждый раз бери меньший текущий элемент;
- когда один массив закончился, допиши хвост второго.

Ожидаемая сложность:
- время: `O(len(a) + len(b))`
- память: `O(len(a) + len(b))`

### 3. Диапазоны в отсортированном массиве

Дан отсортированный массив уникальных чисел. Нужно свернуть соседние подряд идущие числа в диапазоны.

Сигнатура:

```python
def summary_ranges(nums: list[int]) -> list[str]:
    ...
```

Пример:

```python
nums = [0, 1, 2, 4, 5, 7]
# result: ["0->2", "4->5", "7"]
```

Еще пример:

```python
nums = [1, 3, 5]
# result: ["1", "3", "5"]
```

Ограничения:
- `0 <= len(nums) <= 10_000`
- числа отсортированы
- все числа уникальны

Что нужно понять:
- начало текущего диапазона нужно запомнить;
- пока следующее число равно предыдущему `+ 1`, диапазон продолжается;
- когда цепочка рвется, нужно закрыть текущий диапазон.

Ожидаемая сложность:
- время: `O(n)`
- память: `O(n)` на ответ

## Связные списки

### 4. Разворот односвязного списка

Дана голова односвязного списка. Нужно развернуть список и вернуть новую голову.

Класс узла:

```python
class ListNode:
    def __init__(self, value: int, next: "ListNode | None" = None):
        self.value = value
        self.next = next
```

Сигнатура:

```python
def reverse_list(head: ListNode | None) -> ListNode | None:
    ...
```

Пример:

```text
1 -> 2 -> 3 -> 4 -> None

result:
4 -> 3 -> 2 -> 1 -> None
```

Ограничения:
- `0 <= количество узлов <= 100_000`
- нельзя создавать новые узлы для ответа
- нужно менять ссылки существующих узлов

Что нужно понять:
- если сразу поменять `current.next`, можно потерять остаток списка;
- поэтому перед разворотом ссылки сохраняй следующий узел;
- нужны три переменные: `prev`, `current`, `next_node`.

Ожидаемая сложность:
- время: `O(n)`
- память: `O(1)`

### 5. Проверка цикла в односвязном списке

Дана голова односвязного списка. Нужно определить, есть ли в списке цикл.

Цикл означает, что какой-то узел через цепочку `next` снова ведет к уже посещенному узлу.

Сигнатура:

```python
def has_cycle(head: ListNode | None) -> bool:
    ...
```

Пример:

```text
1 -> 2 -> 3 -> 4
     ^         |
     |_________|

result: True
```

Пример без цикла:

```text
1 -> 2 -> 3 -> None

result: False
```

Ограничения:
- `0 <= количество узлов <= 100_000`
- желательно решить без дополнительной памяти

Что нужно понять:
- один указатель двигается медленно;
- второй двигается быстро;
- если цикл есть, быстрый рано или поздно догонит медленный;
- если цикла нет, быстрый дойдет до `None`.

Ожидаемая сложность:
- время: `O(n)`
- память: `O(1)`

### 6. Удалить N-й узел с конца списка

Дана голова односвязного списка и число `n`. Нужно удалить `n`-й узел с конца и вернуть голову списка.

Сигнатура:

```python
def remove_nth_from_end(head: ListNode | None, n: int) -> ListNode | None:
    ...
```

Пример:

```text
head = 1 -> 2 -> 3 -> 4 -> 5
n = 2

result:
1 -> 2 -> 3 -> 5
```

Ограничения:
- `1 <= n <= длина списка`
- желательно решить за один проход

Что нужно понять:
- заведи два указателя;
- сначала сдвинь первый указатель на `n` шагов вперед;
- потом двигай оба указателя, пока первый не дойдет до конца;
- второй будет стоять перед узлом, который нужно удалить;
- dummy-узел упрощает удаление головы.

Ожидаемая сложность:
- время: `O(n)`
- память: `O(1)`

## Строки

### 7. Проверка палиндрома с пропуском лишних символов

Дана строка. Нужно проверить, является ли она палиндромом, если учитывать только буквы и цифры, а регистр игнорировать.

Сигнатура:

```python
def is_palindrome(s: str) -> bool:
    ...
```

Пример:

```python
s = "A man, a plan, a canal: Panama"
# result: True
```

Пример:

```python
s = "race a car"
# result: False
```

Ограничения:
- `0 <= len(s) <= 100_000`

- если символ не буква и не цифра, его нужно пропустить;

### 8. Развернуть порядок слов в строке

Дана строка со словами и пробелами. Нужно вернуть строку, где слова идут в обратном порядке. Сами слова разворачивать нельзя. Лишние пробелы нужно убрать.

Сигнатура:

```python
def reverse_words(s: str) -> str:
    ...
```

Пример:

```python
s = "  hello   from   yandex  "
# result: "yandex from hello"
```

Пример:

```python
s = "a good   example"
# result: "example good a"
```

Ограничения:
- `0 <= len(s) <= 100_000`
- между словами в ответе должен быть ровно один пробел
- в начале и конце ответа пробелов быть не должно

Что нужно понять:
- сначала нужно получить список слов без пустых элементов;
- потом развернуть порядок слов;
- потом собрать строку через один пробел.

Ожидаемая сложность:
- время: `O(n)`
- память: `O(n)`

### 9. Сгруппировать анаграммы

Дан список строк. Нужно сгруппировать строки, которые являются анаграммами друг друга.

Анаграммы состоят из одинаковых символов в разном порядке.

Сигнатура:

```python
def group_anagrams(words: list[str]) -> list[list[str]]:
    ...
```

Пример:

```python
words = ["eat", "tea", "tan", "ate", "nat", "bat"]
# result может быть:
# [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

Ограничения:
- `0 <= len(words) <= 10_000`
- строки состоят из маленьких английских букв

Что нужно понять:
- у анаграмм одинаковый ключ;
- простой ключ: отсортированная строка;
- более быстрый ключ для маленьких английских букв: счетчик из 26 чисел.

Ожидаемая сложность:
- через сортировку каждой строки: `O(n * k log k)`
- через счетчик символов: `O(n * k)`
- память: `O(n * k)` на группы

## Деревья

### 10. Проверить корректность BST

Дано бинарное дерево. Нужно проверить, является ли оно бинарным деревом поиска.

В BST для каждого узла:
- все значения слева строго меньше значения узла;
- все значения справа строго больше значения узла;
- правило выполняется для всех поддеревьев.

Класс узла:

```python
class TreeNode:
    def __init__(
        self,
        value: int,
        left: "TreeNode | None" = None,
        right: "TreeNode | None" = None,
    ):
        self.value = value
        self.left = left
        self.right = right
```

Сигнатура:

```python
def is_valid_bst(root: TreeNode | None) -> bool:
    ...
```

Пример:

```text
    2
   / \
  1   3

result: True
```

Контрпример:

```text
    5
   / \
  1   4
     / \
    3   6

result: False
```

Что нужно понять:
- нельзя проверять только детей текущего узла;
- нужно передавать вниз границы допустимых значений;
- левый ребенок получает верхнюю границу;
- правый ребенок получает нижнюю границу.

Ожидаемая сложность:
- время: `O(n)`
- память: `O(h)`, где `h` - высота дерева

### 11. Проверить симметричность дерева

Дано бинарное дерево. Нужно проверить, является ли оно зеркально симметричным относительно центра.

Сигнатура:

```python
def is_symmetric(root: TreeNode | None) -> bool:
    ...
```

Пример:

```text
      1
     / \
    2   2
   / \ / \
  3  4 4  3

result: True
```

Контрпример:

```text
    1
   / \
  2   2
   \   \
    3   3

result: False
```

Что нужно понять:
- нужно сравнивать не левое с левым, а зеркальные узлы;
- левый потомок первого поддерева сравнивается с правым потомком второго;
- правый потомок первого сравнивается с левым потомком второго.

Ожидаемая сложность:
- время: `O(n)`
- память: `O(h)` для рекурсии или `O(n)` для очереди

### 12. Все пути от корня до листьев

Дано бинарное дерево. Нужно вернуть все пути от корня до каждого листа.

Сигнатура:

```python
def binary_tree_paths(root: TreeNode | None) -> list[str]:
    ...
```

Пример:

```text
    1
   / \
  2   3
   \
    5

result: ["1->2->5", "1->3"]
```

Ограничения:
- если дерево пустое, вернуть пустой список;
- лист - это узел без левого и правого ребенка.

Что нужно понять:
- нужен DFS;
- во время спуска хранится текущий путь;
- когда дошел до листа, путь добавляется в ответ;
- после возврата из рекурсии состояние пути нужно восстановить, если используешь общий список.

Ожидаемая сложность:
- время: `O(n * h)` в простом варианте со сборкой строк;
- память: `O(h)` на рекурсию плюс память под ответ.
