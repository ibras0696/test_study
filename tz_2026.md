

# Задача: консольная мини-игра-опросник с авторизацией

## Цель

Сделать простое приложение в терминале, где пользователь:

* регистрируется или авторизуется
* заходит в свою “учётку”
* проходит небольшой опрос
* смотрит и обновляет свои данные, например возраст
* может выйти из аккаунта
* может завершить программу

---

## Суть проекта

Нужно реализовать **консольную программу**, которая работает как маленькая система пользователей с элементами игры-опросника.

После запуска программа показывает главное меню:

1. Регистрация
2. Вход
3. Выход из программы

После входа пользователь попадает во внутреннее меню аккаунта:

1. Показать мои данные
2. Изменить возраст
3. Пройти опрос
4. Посмотреть результат опроса
5. Выйти из аккаунта

---

# Что должно быть реализовано

## 1. Регистрация

Пользователь вводит:

* логин
* пароль
* возраст

Нужно проверить:

* логин не пустой
* пароль не пустой
* возраст — число
* такой логин ещё не существует

После успешной регистрации пользователь сохраняется в системе.

---

## 2. Авторизация

Пользователь вводит:

* логин
* пароль

Проверка:

* существует ли такой логин
* совпадает ли пароль

Если всё верно — вход выполнен.

Если нет — вывести сообщение об ошибке.

---

## 3. Хранение данных пользователя

У каждого пользователя должны быть свои данные. Минимум:

* логин
* пароль
* возраст
* результат опроса

Например:

```python
{
    "ibragim": {
        "password": "12345",
        "age": 22,
        "score": 0
    }
}
```

---

## 4. Личный кабинет после входа

После авторизации показывать отдельное меню пользователя.

### Доступные действия:

#### Показать мои данные

Вывести:

* логин
* возраст
* текущий результат опроса

#### Изменить возраст

Пользователь вводит новый возраст.
Нужно проверить, что это число и оно больше 0.

#### Пройти опрос

Запускается серия вопросов.

#### Посмотреть результат опроса

Показать количество правильных ответов или итоговые очки.

#### Выйти из аккаунта

Возврат в главное меню.

---

## 5. Опросник

Сделать простой опрос из 3–5 вопросов.

Например:

1. Столица Франции?

   * a) Berlin
   * b) Paris
   * c) Madrid

2. Сколько будет 2 + 2?

   * a) 3
   * b) 4
   * c) 5

3. Python — это?

   * a) язык программирования
   * b) браузер
   * c) операционная система

За каждый правильный ответ начисляется 1 балл.

В конце показать результат:

* сколько правильных
* сколько неправильных
* общий счёт

Результат сохранить в данные пользователя.

---

# Требования к логике

## Обязательно

### 1. Циклы

Программа не должна завершаться после одного действия.
Должны быть циклы для меню.

### 2. Функции

Логику нужно разбить на функции. Например:

* `register_user()`
* `login_user()`
* `show_profile()`
* `update_age()`
* `run_quiz()`
* `main_menu()`
* `user_menu()`

### 3. Проверка ввода

Нельзя доверять вводу пользователя.

Нужно обрабатывать:

* пустые строки
* неправильный формат возраста
* неверные пункты меню
* неверные ответы в опросе

### 4. Разделение состояний

У программы есть два состояния:

* пользователь не вошёл
* пользователь вошёл

И поведение меню зависит от этого.
